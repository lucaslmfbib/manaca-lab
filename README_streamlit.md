## Deploy no Streamlit Community Cloud

O repositório também inclui uma versão em Streamlit.

Arquivos principais:

- `app.py`
- `requirements.txt`

Para publicar, conecte este repositório ao Streamlit Community Cloud e selecione `app.py` como arquivo principal.

> Observação: o Manacá-1B é um modelo relativamente pesado. Em hospedagens gratuitas, o carregamento pode ser lento ou exceder os limites de memória.
