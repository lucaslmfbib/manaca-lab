# 🌳 Manacá Lab

**Experimentação com IA Brasileira**

Interface experimental para exploração do **Manacá-1B**, modelo de linguagem em português brasileiro, com aplicações e experimentações relacionadas à Inteligência Artificial, Ciência da Informação, recuperação da informação e informação jurídica.

## 🧠 Sobre o projeto

O Manacá Lab é um ambiente experimental criado para facilitar testes e estudos com o **Manacá-1B**.

O projeto busca explorar possibilidades de aplicação de modelos de linguagem brasileiros, especialmente nos campos de:

- Inteligência Artificial;
- Ciência da Informação;
- Recuperação da Informação;
- Informação Jurídica;
- Bibliotecas e unidades de informação.

## ⚠️ Importante

O Manacá-1B é um **modelo base**, portanto não possui necessariamente o mesmo comportamento de um chatbot ajustado para seguir instruções.

Os resultados são experimentais e podem apresentar informações incorretas, incompletas ou alucinações.

## 🔬 Próximas etapas

Entre as possibilidades de evolução do projeto estão:

- integração com documentos em PDF;
- RAG (Retrieval-Augmented Generation);
- recuperação de informação jurídica;
- experimentos com legislação e jurisprudência;
- avaliação de alucinações;
- comparação com outros modelos de linguagem.
